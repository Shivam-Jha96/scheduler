The search for ""Discord" schedule message native personal DM or server" returned the following summary:
Discord is rolling out a **native Scheduled Messages** feature[1][2]. 

### 1. Native Feature (Beta)
* **What it is:** Discord has been testing and rolling out a native message scheduler for **both personal DMs and server channels**[2][3]. 
* **How it works (if you have it):** When typing a message, instead of hitting send immediately, you can click/tap a modifier (such as a **`+`** button near the chat box) to set a future time and date for the message to automatically post from your account[4].
* **Availability:** As an active beta feature, it is being released gradually[2][5]. It is **not available to everyone yet**[5]. If you don’t see the option on your desktop or mobile app, your account hasn't been included in the rollout phase[2]. You cannot manually request access[2].

---

### 2. Alternatives If You Don't Have the Native Beta Yet

If you need to schedule messages right away and don't have access to the native beta, you have to use alternative methods depending on where you want to post:

* **For Servers:** 
  * **Bots:** You can invite third-party Discord bots designed for scheduling (such as ScoutBot, Embed Generator, or various webhook-backed automation tools) that allow you to plan one-off or recurring server announcements[2][6][7].
  * **Webhooks:** Useful for automated or cross-platform scheduling setups[2][8].
* **For Personal DMs / Reminders:** 
  * If you just want to remember to send something later without using external bots, you can use Discord's **Reminders** feature (right-click a message or use built-in reminder prompts) to ping yourself when it's time to type and send the message manually[4].
