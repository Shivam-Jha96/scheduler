The search for ""KakaoTalk" schedule message native Jordy" returned the following summary:
When KakaoTalk first rolled out its native **Message Scheduling** feature via its virtual assistant **"Talk Secretary Jordy" (톡비서 죠르디)**, scheduled messages came with a distinct **Jordy icon/badge** attached to the message bubble[1][2]. This indicated to the recipient that the text was sent automatically via a tool rather than typed out in real-time[1].

However, due to user feedback regarding privacy and natural communication, KakaoTalk released an update (v10.0.5) that **removed the Jordy icon/badge** from scheduled messages[3][4]. 

### How the KakaoTalk Native Schedule Message Feature Works:

1. **Accessing the Feature:**
   * **Mobile (iOS / Android):** Tap the **`+` (plus)** button next to the chat text input box or use the `#` (hash/sharp) menu shortcut inside a chat room, then select **Message Scheduling** (often managed through Jordy's tools/your "Chat with yourself" briefing tab)[5][6].
   * **PC Version:** Click the **Jordy icon** or tool button near the chat input area[6].

2. **Setting the Schedule:**
   * Type your message, choose the desired date and time (in 5-minute increments), and set whether you want a reminder notification beforehand[5][6].
   * You can manage or cancel up to 10 active scheduled messages at a time through your "Chat with yourself" room (where Jordy acts as your assistant)[2][6].

3. **Current Appearance:**
   * When the scheduled time arrives, the message sends automatically[5]. 
   * Because the **Jordy badge/icon was removed**, the message now looks completely normal—just like any other standard text message sent manually by you[4].
