## 1. System Overview & Functional Scope

The **WhatsApp Message Scheduler Bot** is an automated messaging system operating directly inside WhatsApp. It allows users to create, view, modify, and delete scheduled messages for future delivery to individual contacts or group chats.

The system integrates directly with two messaging backends:
1. **Personal Account Automation (Mode B - Baileys WebSocket):** Full peer-to-peer delivery from the user's personal phone number using companion device session credentials.
2. **Official Business API (Mode A - Cloud API Assistive Redirector):** Meta policy-compliant reminder system delivering interactive `wa.me` CTA buttons with Utility Template fallback.
